パドルのことば

重さ
軽いほど速く振れてネット前で動かしやすく、重いほど強いボールを打ちやすくなります。
しん（芯）の厚さ
厚い（16mmくらい）ほどボールをやわらかく受け止めてコントロールしやすく、うすい（13〜14mmくらい）ほどボールが速く飛びます。
形
スタンダード（幅広）はボールが当たりやすい場所が広く、ロング（細長い）は遠くまで届いてパワーや回転をかけやすくなります。ハイブリッドはそのあいだです。
面の素材
カーボンはコントロールと回転、ガラス繊維（ファイバーグラス）は球のいきおいが出やすいといわれます。
グリップの太さ
太すぎると手首が動かしにくく、腕に負担がかかることも。迷ったら細めを選び、グリップテープで太くできます。
